# Rafaqat Babar & Co. — Portfolio Website

Premium accounting, audit, taxation, advisory and financial consultancy portfolio website.

## Design direction
- Theme: Precision in Finance
- Feel: soft, premium, trustworthy, intelligent
- Primary: Deep Forest Green `#123C32`
- Secondary: Soft Green `#2F6F5E`
- Sage: `#A8BDAF`
- Background: Warm Ivory `#F7F6F1`
- Text: Charcoal `#17201D`
- Accent: Gold `#B89B5E`
- Typography: Manrope + Inter
- Animation: Motion / Framer Motion
- Optional 3D: React Three Fiber

## Recommended stack
Next.js + TypeScript + Tailwind CSS + shadcn/ui + Motion + React Hook Form + Zod.
