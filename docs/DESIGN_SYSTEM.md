# Design System

## Colors

- Forest: #123C32
- Green: #2F6F5E
- Sage: #A8BDAF
- Ivory: #F7F6F1
- Charcoal: #17201D
- Muted: #68736E
- Gold: #B89B5E

## Typography

- Headings: Manrope, 600–700
- Body: Inter, 400–500
- Optional editorial accent: DM Serif Display

## Style

Premium, calm, editorial, financial, trustworthy.

Avoid neon, crypto aesthetics, excessive glassmorphism and excessive 3D.
