# Rafaqat Babar & Co. Website Documentation

This folder contains the complete website direction, information architecture, visual system, technology choices, SEO plan, animation rules and development roadmap.

## Source basis

The project scope is based on the uploaded **Rafaqat Babar & Co. Website Quotation** from 3 Minds Co. The quotation specifies a modern secure professional corporate website reflecting Chartered Accountancy, Audit, Taxation, Advisory and Financial Consultancy expertise, with responsive design, SEO setup, WhatsApp/inquiry integration, launch support and future content-update capability.

## Core concept

**Precision in Finance**

The website is a professional portfolio/corporate profile site. It should not become an accounting dashboard or a complex client portal.

## Visual direction

Soft premium financial advisory design:
- Warm ivory backgrounds
- Deep forest green
- Sage supporting tones
- restrained gold accent
- Manrope/Inter typography
- editorial whitespace
- thin borders
- subtle financial line graphics

## Animation

Use Motion for:
- page entrance
- scroll reveal
- card hover
- CTA interactions
- number counters

Optional React Three Fiber:
- one hero visual
- only if performance remains excellent

Respect `prefers-reduced-motion`.

## SEO

Implement:
- unique title and description per page
- one H1 per page
- semantic H2/H3 hierarchy
- canonical URLs
- sitemap.xml
- robots.txt
- Organization/ProfessionalService/LocalBusiness schema where accurate
- Article schema for insights
- descriptive image alt text
- internal linking
- local office information
- Google Search Console
- performance optimization

## Content governance

Do not invent:
- client counts
- revenue
- certifications
- testimonials
- case studies
- statistics
- office details
- team credentials

All public claims must be approved by the firm.

## Production checklist

1. Replace placeholder content.
2. Add approved logo and images.
3. Add verified contact information.
4. Connect inquiry API to approved email/CRM.
5. Add WhatsApp link.
6. Add analytics and Search Console.
7. Validate metadata and structured data.
8. Test forms.
9. Test mobile/tablet/desktop.
10. Run Lighthouse.
11. Verify sitemap and robots.
12. Deploy.
